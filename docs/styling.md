# Styling

Tailwind v4 + shadcn/ui, light theme only. Tokens live in `src/index.css` (`:root` for values, `@theme inline` to expose them as classes). The living reference is the `/design` page (`src/pages/design.tsx`).

## Rules

1. **Scale classes only.** Every Tailwind value comes from the theme scale: `p-4`, `gap-3`, `text-caption`, `max-w-popup`, `shadow-card`. Square-bracket arbitrary values are banned: write `p-4`, never `p-[16px]`; `text-caption`, never `text-[13px]`. When nothing on the scale fits, add a named token to `@theme` in `src/index.css` (with a comment saying where it's used), then use its class. Variant selectors like `data-[state=on]:` and `[&_svg]:` are selectors, not values, and stay allowed. `npm run lint:tw` must pass.
2. **Semantic colour.** Use role tokens (`bg-card`, `text-muted-foreground`, `text-success`), never raw palette colours or hex. Colour carries meaning only: `brand` indigo = in progress / focus, `success` = money received, `warning` = needs attention, `destructive` = failed. Everything else is greyscale ink on paper.
3. **Numbers are tabular.** Any money, quantity or counter gets `num`. Hero totals use `display` with a `text-display*` size. Format through `src/lib/format.ts`.
4. **Every state lives on `/design`.** A new component or state gets a static example there in the same change.
5. **One primary per screen.** The ink pill (`Button` default, `size="xl"` for CTAs) appears once; the rest are `outline` or `ghost`.

## Scale

| Need | Class |
|---|---|
| 12 / 13 / 14 / 15 / 20 px text | `text-xs` / `text-caption` / `text-sm` (body) / `text-md` / `text-xl` |
| 44 / 56 / 88 / 160 px display | `text-display-sm` / `text-display` / `text-display-lg` / `text-display-xl` |
| App column width (400) | `max-w-popup` |
| Elevation | `shadow-card`, `shadow-raised`, `shadow-pill`, `shadow-inset`, `shadow-active` |
| Mono technical label | `eyebrow` |
| Staggered entrance | `reveal` + `style={{ '--i': n }}` |

## shadcn components

`src/components/ui/*` is generated by the shadcn CLI and skipped by `lint:tw`. When you edit one of those files, bring every class you touch onto the scale (as done in `button.tsx`). Product components live in `src/components/domain/`.
